## Description

This repository contains the microservice project for the **DevOps and Software Engineering Capstone Project** as well as continuous integration and continuous deployment pipelines using:
- Automated linting with `flake8`
- Automated unit testing with `nosetests`
- Continuous Integration build validation using GitHub Actions
- Containerized workflows and deployment with Tekton pipelines on OpenShift
