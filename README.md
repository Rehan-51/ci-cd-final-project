## Description

This repository contains the project for **ci-cd-final-project** as part of the CI/CD course. It demonstrates continuous integration and continuous deployment pipelines using:
- Automated linting with `flake8`
- Automated testing with `nosetests`
- Container workflows and deployment with Tekton pipelines on OpenShift
